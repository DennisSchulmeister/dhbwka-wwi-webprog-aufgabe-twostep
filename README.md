# Webprogrammierung / Aufgabe / TwoStep

Dies ist eine **Übungsaufgabe** aus der Vorlesung **Webprogrammierung** (Wirtschaftsinformatik, DHBW Karlsruhe), Kategorie *JavaScript*.

Eine kleine Musikdatenbank mit Ragtime-Komponisten und -Stücken wird als verschachtelte JavaScript-Datenstruktur modelliert und mit verschiedenen Schleifenarten ausgegeben.

## Hinweis

Nur der Unterordner Webservice/ wird übernommen; Beschreibung/ entfällt, da die Aufgabenstellung künftig im README steht.

Dieses Repository ist Teil der Quellcodes [dhbwka-wwi-webprog-quellcodes](https://github.com/DennisSchulmeister/dhbwka-wwi-webprog-quellcodes) zur Vorlesung Webprogrammierung.
